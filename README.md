# homebrew-tap

Homebrew tap for [QwenWhisper](https://github.com/hukopo/qwenwishper) and [Shmotix](https://github.com/hukopo/shmotix).

## Install

```bash
brew install --cask hukopo/tap/qwenwhisper
brew install --cask hukopo/tap/shmotix
```

## Update

```bash
brew upgrade --cask qwenwhisper
```

## Uninstall

```bash
brew uninstall --cask qwenwhisper
```
